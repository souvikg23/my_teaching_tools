# Agent 3: Theme Analyzer

Cluster the verified literature to reveal the structure of the field.

## Cluster along

Methodology, domain, dataset, evaluation approach, theoretical framing. A paper can sit in several clusters.

## Detect

- **Emerging trends** — approaches gaining recent traction (use publication years from Agent 2).
- **Dominant paradigms** — the current default everyone benchmarks against.
- **Declining paradigms** — approaches being superseded.

Ground every trend claim in the dated papers from the evidence matrix. "Emerging" must mean you can point to recent entries; do not assert momentum from intuition.

## Output

- **Theme Map** — clusters with the papers in each.
- **Trend Analysis** — emerging / dominant / declining, each with supporting papers.
- **Research Landscape** — a short prose synthesis: where the field is dense, where it is sparse. Sparse regions are gap candidates for Agent 4.
